Write one shared [[interview guide]], then a variant per expert profile that adds the questions only that profile can answer. In each interview: qualify the respondent first (role, kind of accounts handled), ask for concrete cases before showing any hypothesis, and show provisional results only at the end. Keep every statement linked to its speaker and turn; treat a claim as solid when profiles with different positions agree.

Condition: at least two experts per profile are reachable, and someone can tell which profile each one belongs to.

Limitation: the picture is only as wide as the profiles interviewed; a position nobody was asked about stays invisible ([[sampling bias]]).

Knowledge-curation platform organised in [[knowledge]] stores. Each store holds curated [[artifact]]s (a [[brief]], playbooks, a [[concept map]]) and a document library; agents read and write them through an [[MCP server]].

Its core loop is [[content curation]]: collect, evaluate through [[feedback]], update. A store can link to a master store and read its [[rules]] without copying them, which keeps one [[single source of truth]].

All the activities that make a system available for use: install, configure, switch on, and watch it run. An occurrent: it happens, rather than exists.

A deployment is safer when it is staged ([[crawl-walk-run]]): first observe, then enforce, then automate, so that [[human-in-the-loop]] judgement comes before the system is allowed to block anything. For a model, deployment is what turns training into [[Inference]].

**Example (knowledge glossary, 2026-11-22):** the logic gate was deployed in lots: a light environment, the judge (`reason.py gate`), Claude Code hooks in warning mode, then blocking mode (`KG_GATE=block`), an MCP write tool, a CI workflow and a GitHub ruleset.

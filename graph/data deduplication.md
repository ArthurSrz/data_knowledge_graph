Data processing technique to eliminate duplicate copies of repeating data

In a document library: an **exact duplicate** has the same name (often with a "(1)" suffix from a second download) *and* the same file size and page count. Same title with a different size is a different version, and a .md conversion next to its PDF is a different format: neither is a duplicate. Archive one copy (reversible, kept for history) rather than delete, and keep the copy without the suffix.

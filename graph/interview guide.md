The written list of topics and questions an interviewer follows in a [[semi-structured interview]]: it fixes what must be covered, not the order or the follow-ups.

Practice from an [[elicitation interview]] campaign run with an AI interviewer:
1. **One shared guide, then variants per profile.** Common questions stay; profile-specific ones are added, because each [[subject-matter expert]] has seen a different part of the [[domain]].
2. **A short version** (e.g. 30 min) is derived from the full one, not written separately.
3. **Brief before the meeting.** Each interview gets a brief built from the guide; it must be validated before the meeting, or the interviewer joins without it.
4. **Loop back after.** Post-interview analysis (technique, missing answers) is carried back into the guide, so the guide is an [[artifact]] that improves interview after interview.

**Measurement bias**: estimate of the systematic measurement error (Wikidata).

In qualitative work, the measuring instrument is the [[codebook]] and the coder: a code applied inconsistently across documents biases every count built on it. Hence piloting the coding on a few documents before applying it to the whole set ([[qualitative coding]]).

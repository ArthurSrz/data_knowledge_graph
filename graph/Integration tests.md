Test of a few real parts wired together, after [[Unit tests]] and before the [[end-to-end test]]: real data, but not yet the real platform.

It catches what unit tests cannot: two parts that each work alone but disagree at their seam (file names, formats, encodings).

**Example (knowledge glossary, 2026-11-22):** the logic gate is run on the real graph with `process owner` placed under both [[person]] and [[business process]] → refused (disjointness, [[continuant]] vs [[occurrent]]); the version using `accountable for` → accepted. A second integration test caught a real bug: note names with spaces and accents were split by git, so the gate silently accepted a faulty note.

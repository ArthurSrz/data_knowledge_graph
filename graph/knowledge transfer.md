**Knowledge transfer**: sharing knowledge so that someone else can solve a problem with it.

Unlike plain [[information transfer]], it has to carry know-how ([[tacit knowledge]]). In a knowledge store it happens through three channels: interviews, documents and usage feedback. Every correction a user makes to the agent is a transfer that is lost unless someone writes it into the store.

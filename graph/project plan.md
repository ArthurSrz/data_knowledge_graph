Formal, approved document used to guide both project execution and project control.

Writing rule: an action states what is needed ("interlocutor to identify: a manager who receives the escalated cases"), not what the team did about it ("asked X on date Y"). The plan holds the shared need; follow-up messages stay in the team's own to-do. Open points left after a workshop get their own section, each with the source meeting link, so decided and undecided items stay apart.

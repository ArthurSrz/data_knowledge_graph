**Changeset**: atomic group of changes between successive revisions in a version-control repository.

In Clarifeye, one approved edit becomes a set of artifact versions written together (e.g. Edit 3 = `process-capture-method` v179–181 + `contradictions-and-gaps-to-review` v16). The changelog `description` plays the role of the commit message. The unit of [[change control]].

**Responsibility assignment matrix (RACI)**: table that crosses the situations in a [[process]] with the roles involved, marking each cell Responsible, Accountable, Consulted or Informed.

When a [[Business Process Model and Notation]] lane is split into two roles, the RACI follows: one row per task per lane, and the matrix's description must stop saying the roles are "split here" from a merged lane. Row count changing is the visible sign; compare with any earlier export.
